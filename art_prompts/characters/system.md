# System
**Role:** the game's disembodied interface voice (Ch0 arrival, Ch3, Ch7 endings). Not a person —
an arcane HUD presence. Use for the "SYSTEM INITIALIZING" moments as a visual motif, not a body.

## Portrait prompt
A floating arcane interface entity — no body, a construct of light. A rotating ring of glowing
runic glyphs and holographic panels of soft cyan-and-gold light, centered on a single bright
diamond core. Concentric magic circles, thin data-threads of light radiating outward, faint
particle field. Clean, sacred-tech, ethereal. Centered on a dark/transparent background.

## Idle animation frames
- **Frame 1:** base, ring slow, core steady.
- **Frame 2:** the runic ring rotates; panels flicker in and glyphs light in sequence.
- **Frame 3:** the diamond core flares (an "alert"/"initializing" pulse) and rings expand outward.
- **Frame 4:** core settles, ring keeps rotating (loops to Frame 1).

--- STYLE: high-resolution pixel art, detailed 16-bit SNES-era JRPG style, crisp clean pixels, vibrant saturated palette, dithered gradients, strong glow and rim lighting, sacred-tech fantasy UI motif. 1:1.
--- NEGATIVE: blurry, 3D render, realistic photo, readable text, watermark, signature, human figure, extra limbs.
